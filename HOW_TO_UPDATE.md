# How to update the website

Live at **https://niklomax.com** — GitHub Pages, repo `niklomax/niklomax.github.io`.

Two data files control everything. You never need to touch the HTML.

## Publishing a change

After editing `publications.json` or `projects.json`, upload the changed file to the repo. Either:

- **On github.com**: open the file in the repo, click the pencil (or *Add file → Upload files*), and commit to `main`. The site rebuilds automatically within a minute or two.
- **With git**: `git add -A && git commit -m "update" && git push`

To preview locally first: run `python3 -m http.server` in this folder and open http://localhost:8000 (opening `index.html` directly won't load the data files).

## Adding a new publication

1. Write the summary `.md` file in `OUTPUTS/Paper summary/` as usual. The frontmatter fields needed are:

   ```yaml
   ---
   year: 2026
   type: "Journal Article"
   title: "Full title here"
   authors: "Last, F., Last, F., & Lomax, N."
   journal: "Journal Name"
   volume: "1"
   issue: "2"
   pages: "100-120"
   doi: "10.xxxx/xxxxx"
   ---
   ```

   Then write the body with the four bold-headed sections:
   ```
   **Background to the study.** ...
   **Importance to the field.** ...
   **Methods.** ...
   **Key findings.** ...
   ```

2. Run the build script from this folder:

   ```bash
   python3 scripts/build_publications_json.py
   ```

   This reads all `_summary.md` files and overwrites `publications.json`.

3. Commit and push both the new `.md` file and the updated `publications.json`.

## Updating a project (adding, editing, or marking complete)

Edit `projects.json` directly. Each project entry looks like this:

```json
{
  "name": "Full project name",
  "short": "Abbreviation",
  "status": "active",          ← change to "completed" when it ends
  "funder": "Funder name",
  "url": "https://...",
  "tagline": "One sentence, shown on the card.",
  "role": "Your role in the project",
  "partners": "Partner list as a string",
  "start_year": 2024,
  "end_year": null,            ← fill in when project ends
  "description": [
    "First paragraph of expanded detail.",
    "Second paragraph."
  ]
}
```

To add a new project: copy an existing entry, paste it at the top of the array (active projects show first), and fill in the fields.

To mark a project complete: change `"status": "active"` to `"status": "completed"` and set `"end_year"`.

## File structure

```
website/
├── index.html              ← the site (do not edit directly)
├── publications.json       ← generated by the script
├── projects.json           ← edit manually
├── scripts/
│   └── build_publications_json.py
└── HOW_TO_UPDATE.md
```

The `publications.json` and `projects.json` files are the single source of truth. The HTML reads them at load time — change the data, the site changes.
